## 更新内容

- **文献阅读与笔记**：支持导入或直接拖入参考文献 PDF，连续滚动阅读，保存高亮、划线和带页码的笔记。笔记支持 Markdown 与 LaTeX 公式；没有文字层的 PDF 也可框选高亮、拖动划线。
- **投稿历程**：按时间线维护投稿、审稿、编辑决定、rebuttal 和修订；关联论文版本并归档投稿 PDF、源文件与补充材料。支持粘贴材料后由 Agent 增量整理，同一进展继续使用原会话；审稿原文与原始评分独立保留。
- **研究脉络**：概况新增研究演化和论点与证据视图，串联重要实验、主张、思路转变及投稿修改，并可跳转到对应来源。
- **项目搜索**：通过 Ctrl / ⌘ K 搜索文稿、文献引文与笔记、实验和投稿记录，直接定位相关内容。
- **写作与模板**：PDF 预览改为连续滚动，支持 Ctrl / ⌘ 点击定位 TeX 源码；新增全局写作模板导入，以及已有文稿切换模板、预览文件变动和版本差异。
- **实验管理**：支持重要度标记、已读未读状态，并显示最后更新时间和运行次数。
- **导航与分栏**：左侧改为图标导航，悬停显示名称。文献、写作、会话、实验、概况等分栏可拖动调整宽度并自动保存，双击恢复默认。
- **会话与 Agent**：修复终端选中文字复制，完善浅色配色、自动发送和统一权限配置；更新项目初始化生成的 AGENTS.md，说明论文、实验、投稿、文献与研究脉络的读取和维护入口。

## 下载

按系统及 CPU 架构选择安装包：

| 系统 | 架构 | 文件 |
| --- | --- | --- |
| Windows | x64 / ARM64 | `.exe` |
| macOS | Intel x64 / Apple Silicon ARM64 | `.dmg` |
| Linux | x64 / ARM64 | `.AppImage`、`.tar.gz`、`.deb`、`.rpm` |

发布附件包含 12 个安装包或压缩包、`SHA256SUMS.txt` 和 `LICENSE`。用户项目数据保存在本地；当前没有应用内自动更新，请下载对应安装包升级。

Windows 安装包尚未使用发行商证书；macOS DMG 采用 ad-hoc 签名，尚未 notarize，安装时可能出现系统安全提示。
